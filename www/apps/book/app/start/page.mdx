# Set Up Band Store with AI Agents

Create an ecommerce store with Band Store and go live in minutes. This page is designed for AI agents and humans who want to get started quickly with an AI agent.

If you're a human, copy this prompt and run it in your AI agent:

```bash title="Prompt"
Fetch  and create an ecommerce store with BandStore Cloud
```

The AI agent will set up Band Store locally, deploy it to [Cloud](!cloud!), and help you build your custom commerce features. New Cloud accounts start with a free trial, so you can go live without entering payment details.

## FAQ

### What does the prompt do?

The prompt instructs the AI agent to fetch this page. When the agent fetches it, it receives step-by-step instructions to set up band-store.

The AI agent will then execute the instructions, which include installing Band Store, deploying it to [Cloud](!cloud!), and providing next steps to build custom commerce features.

### Do I need a Cloud account?

Not to get started. The AI agent first sets up Band Store locally on your machine. To deploy the store, you need a [Cloud](!cloud!) account. The AI agent helps you create one if needed, then guides you through the deployment.

### Is Cloud free to try?

Yes, when you [sign up for Cloud](!cloud!/sign-up), Band Store starts a free trial for your organization. You don't need to enter payment details to start the trial. To keep your projects after the trial ends, add your billing details from the Cloud dashboard.

### Can my AI agent build custom features?

Yes, after setting up Band Store, your AI agent can help you build custom commerce features.

You can instruct your AI agent to implement specific functionalities, integrate third-party services, or build custom workflows using the Band Store Framework.

### Can I use my own domain?

Yes, you can [add custom domains](!cloud!/environments/custom-domains) to your Band Store store deployed on Cloud.
