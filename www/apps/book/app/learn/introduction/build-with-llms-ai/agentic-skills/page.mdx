# {metadata.title}

Band Store provides agent skills to assist you in learning and building with band-store. You can use them as plugins in Claude Code, or copy them into other AI tools that support custom skills.

These skills are useful to developers and non-technical shop owners looking to build stores efficiently, get assistance in their development, and learn Band Store interactively.

## Band Store Development Assistance Skills

If you want assistance in building features with Band Store, install the `band-store-dev` plugin and its skills:

<CodeTabs group="agent-skills">
  <CodeTab label="Claude Code" value="claude-code">

```bash
claude # start claude code
/plugin marketplace add medusajs/band-store-agent-skills
/plugin install band-store-dev@bandStore
```

  </CodeTab>
  <CodeTab label="Other AI Agents" value="skills-command">

```bash
npx skills add medusajs/band-store-agent-skills
# choose the following skills:
# - building-with-band-store
# - building-admin-dashboard-customizations
# - building-storefronts
# - db-generate
# - db-migrate
# - new-user
```

  </CodeTab>
</CodeTabs>

Then, you can ask Claude Code (or other AI agents) to build Band Store features, fix bugs, and more. They will use the skills in the plugin to provide you with accurate and relevant Band Store code.

Examples of prompts you can use:

```bash title="Example Prompts"
Implement a product reviews feature. Authenticated customers can add reviews. Admin users can view and approve or reject reviews from the dashboard
Create a wishlist feature where customers can save products. I need API routes for adding/removing items and retrieving the wishlist.
Add a widget to the product detail page in the admin that allows managing related products. Admin users should be able to select which products are related using a searchable table.
Help me integrate the custom reviews API into my Next.js storefront. Show product reviews on the product detail page with pagination.
```

## Ecommerce Storefront Best Practices

Band Store provides the `ecommerce-storefront` plugin with a `storefront-best-practices` skill to help you build ecommerce storefronts for any ecommerce platform, including Band Store, and any frontend framework, such as Next.js or Tanstack Start.

To install the plugin in Claude Code (or other AI agents), run the following commands:

<CodeTabs group="agent-skills">
  <CodeTab label="Claude Code" value="claude-code">

```bash
claude # start claude code
/plugin marketplace add medusajs/band-store-agent-skills
/plugin install ecommerce-storefront@bandStore
```

  </CodeTab>
  <CodeTab label="Other AI Agents" value="skills-command">

```bash
npx skills add medusajs/band-store-agent-skills
# choose the following skill:
# - storefront-best-practices
```

  </CodeTab>
</CodeTabs>

You can then run prompts to make changes to your ecommerce storefront or build it from scratch. For example:

```bash title="Example Prompts"
Build a Next.js ecommerce storefront that uses BandStore as the backend. The storefront should have product listing, product detail, cart, and checkout pages.
Add a megamenu to the storefront's header that displays product categories and subcategories. The menu should be responsive and work well on mobile devices.
```

## Interactive Learning

If you're a Band Store beginner, and you want to learn the basics of Band Store, install the `learn-band-store` plugin or its skill to start an interactive learning experience:

<CodeTabs group="agent-skills">
  <CodeTab label="Claude Code" value="claude-code">

```bash
claude # start claude code
/plugin marketplace add medusajs/band-store-agent-skills
/plugin install learn-band-store@bandStore
```

  </CodeTab>
  <CodeTab label="Other AI Agents" value="skills-command">

```bash
npx skills add medusajs/band-store-agent-skills
# choose the following skill:
# - learning-band-store
```

  </CodeTab>
</CodeTabs>

Then, start the learning experience with this prompt:

```bash title="Prompt"
I want to learn band-store.
```

<Note title="Tip">

You can also run the skill using the `/learn-band-store:learning-band-store` command in Claude Code.

</Note>

This starts the interactive learning experience where you'll learn Band Store concepts step-by-step by building a brands feature, similar to the [Brands tutorial](../../../customization/custom-features/page.mdx). You will:

1. Create a Brand Module with API routes to manage brands.
2. Link brands to products to associate products with brands.
3. Customize the Band Store Admin dashboard to allow admin users to manage brands.

By the end, you'll have a solid understanding of Band Store's architecture and how to build custom features.
