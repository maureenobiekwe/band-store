# {metadata.title}

In this guide, you'll learn about the color classes available in Band Store UI and how to use them.

## Overview

Band Store UI provides Tailwind CSS classes for colors from the Band Store design system. These classes can be used to style components and elements consistently across your Band Store and standalone applications.

To view the colors in the list below in dark mode, switch the documentation's theme from the menu in the top right.

To copy a color's Tailwind CSS class from the list below, click on it.

### How to Use the Band Store UI Colors

You can use the color classes in your Band Store Admin customizations or standalone projects that have the `@band-store/ui` package installed.

You can apply the color classes as CSS classes to any element.

For example, to set the background color of the document's body:

```tsx
<body className="bg-band-store-bg-base">
  ...
</body>
```
