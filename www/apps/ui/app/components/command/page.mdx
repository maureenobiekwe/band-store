## Usage Outside Band Store Admin

If you're using the `Command` component in a project other than the Band Store Admin, make sure to include the `TooltipProvider` somewhere up in your component tree, as the `Command.Copy` component uses a [Tooltip](../tooltip/page.mdx#usage-outside-band-store-admin):

```tsx
<TooltipProvider>
  <Command>
    <code>yarn add @band-store/ui</code>
    <Command.Copy
      content="yarn add @band-store/ui"
      className="ml-auto"
    />
  </Command>
</TooltipProvider>
```
