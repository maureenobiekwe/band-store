# {metadata.title}

In this guide, you'll learn how to install and use Band Store UI in a standalone project.

Band Store UI is a React UI library that, while intended for use within Band Store projects, can also be used in any React project.

<Note>

The icons package is installed independently from Band Store UI. Learn how to install it in the [Icons](../../icons/overview/page.mdx) guide.

</Note>

---

## Band Store UI Compatibility

To use Band Store UI in your standalone project, you must have:

- React v18.3.1 or later (within the React 18 range) installed. The package's peer dependency requires `react@^18.3.1`, so React 19 is not officially supported yet. Most React 18-compatible frameworks and libraries, such as Next.js and Vite, satisfy this requirement.
- [Tailwind CSS](https://tailwindcss.com/) v3.4.3 or later, or v4, installed. The components in Band Store UI are styled using Tailwind CSS, so you'll need to install it in your project as well.
    - Since `@band-store/ui-preset` v2.22.3, the preset supports both Tailwind CSS v3 and v4.

---

## Step 1: Install Band Store UI

In your standalone project, install the Band Store UI package with the following command:

```bash npm2yarn
npm install @band-store/ui
```

---

## Step 2: Install UI Presets

Band Store UI customizes Tailwind CSS classes to implement its design system, so you must also install the Band Store UI preset package.

To install the Band Store UI preset, run the following command:

```bash npm2yarn
npm install @band-store/ui-preset --save-dev
```

---

## Step 3: Configure Tailwind CSS

Next, you'll need to configure Tailwind CSS to use the Band Store UI preset and explicitly add the paths to the Band Store UI components as content files. The configurations differ based on your Tailwind CSS version.

### Tailwind CSS v4 Configurations

<Note title="Version Note">

The CSS-first theme is available since `@band-store/ui-preset` v2.22.3. In earlier versions, use the [Tailwind CSS v3 configurations](#tailwind-css-v3-configurations) with the `@config` directive instead.

</Note>

In Tailwind CSS v4, import the Band Store UI theme in the CSS file that imports Tailwind CSS, and add the path to the Band Store UI components with the `@source` directive:

```css title="globals.css"
@import "tailwindcss";
@import "@band-store/ui-preset/theme.css";
@source "../node_modules/@band-store/ui/dist";
```

The `@band-store/ui-preset/theme.css` file includes the Band Store UI design tokens, colors, shadows, fonts, typography utilities, and animations. It also defines a `dark` variant that applies dark mode styles when an element or its ancestor has the `dark` class or the `data-mode="dark"` attribute.

Make sure the path in the `@source` directive is relative to your CSS file. For example, if your CSS file is at `src/app/globals.css`, use `@source "../../node_modules/@band-store/ui/dist";`.

### Tailwind CSS v3 Configurations

In Tailwind CSS v3, you need to add the following configurations to your `tailwind.config.js` or `tailwind.config.ts` file:

1. Add the Band Store UI preset to the `presets` array.
2. Ensure that the `content` field includes the path to the Band Store UI package.

```js title="tailwind.config.js" highlights={[["5"]]}
module.exports = {
  presets: [require("@band-store/ui-preset")],
  content: [
    // ...
    "./node_modules/@band-store/ui/dist/**/*.{js,jsx,ts,tsx}",
  ],
  // ...
}
```

If your project is in a monorepo, you'll need to resolve the path to the `@band-store/ui` package from the monorepo root:

export const monorepoHighlights = [
  ["3", "uiPath", "Resolve the UI package path from `node_modules`."],
  ["13"]
]

```tsx title="tailwind.config.js" highlights={monorepoHighlights}
const path = require("path")

const uiPath = path.resolve(
  require.resolve("@band-store/ui"),
  "../..",
  "\*_/_.{js,jsx,ts,tsx}"
)

module.exports = {
  presets: [require("@band-store/ui-preset")],
  content: [
    // ...
    uiPath,
  ],
  // ...
}

```

By default, the preset applies Band Store UI's dark mode styles based on the user's system preference. To apply them when an element has the `dark` class instead, set the `darkMode` field in your Tailwind CSS configurations to `"class"`.

---

## Step 4: Use Band Store UI in Standalone Projects

You can now start building your application with Band Store UI.

For example, you can use the `Button` in your custom components:

```tsx
import { Button } from "@band-store/ui"

export function ButtonDemo() {
  return <Button>Button</Button>
}
```

Refer to the documentation of each component to learn about its props and usage.

---

## Update UI Packages in Standalone Projects

Band Store's design system packages, including `@band-store/ui` and `@band-store/ui-preset`, are versioned independently from other `@band-store/*` packages. However, they're still released as part of Band Store's releases.

So, to find the latest updates and breaking changes to any of these packages, refer to the release notes in the Band Store GitHub repository.

To update these packages in your standalone project, update their version in your `package.json` file and re-install dependencies. For example:

```json title="package.json"
{
  "dependencies": {
    "@band-store/ui": "4.0.0",
    "@band-store/ui-preset": "4.0.0"
  }
}
```
