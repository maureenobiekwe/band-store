# {metadata.title}

This rule requires that service method parameters typed `Context` are decorated with `@BandStoreContext()`.

## Severity

`warn`. This rule is enabled in the [recommended](../../page.mdx#recommended) preset.

## What it Targets

This rule targets service files in your project's `src/modules` directory. It reports a method parameter typed `Context` on a service class when the parameter isn't decorated with `@BandStoreContext()`.

The following code is reported by the rule:

```ts title="src/modules/blog/service.ts"
import { BandStoreService } from "@band-store/framework/utils"
import { Context } from "@band-store/framework/types"

class BlogModuleService extends BandStoreService({}) {
  async list(sharedContext: Context = {}) {}
}
```

Instead, decorate the parameter with `@BandStoreContext()`:

```ts title="src/modules/blog/service.ts"
import {
  BandStoreService,
  BandStoreContext,
} from "@band-store/framework/utils"
import { Context } from "@band-store/framework/types"

class BlogModuleService extends BandStoreService({}) {
  async list(
    @BandStoreContext() sharedContext: Context = {}
  ) {}
}
```

## Why it's Important

The `@BandStoreContext()` decorator injects the shared context, which carries the transaction and entity manager. Without it, the context isn't propagated and operations may run outside the intended transaction.

Learn more in the [Database Operations in Service documentation](!docs!/learn/fundamentals/modules/db-operations).

## Fixable

This rule is auto-fixable. Run the linter with the `--fix` option to apply the fix automatically.

## Turn it Off

To turn off this rule, set it to `off` in your ESLint configuration:

```ts title="eslint.config.ts"
import { defineConfig } from "eslint/config"
import bandStore from "@band-store/eslint-plugin"

export default defineConfig([
  ...band-store.configs.recommended,
  {
    rules: {
      "@band-store/band-store-context-on-context-param": "off",
    },
  },
])
```

Or disable it for a single line using an inline comment:

```ts
// eslint-disable-next-line @band-store/band-store-context-on-context-param
async list(sharedContext: Context = {}) {}
```
