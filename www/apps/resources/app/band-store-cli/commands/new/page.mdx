# {metadata.title}

Create a new Band Store application. Unlike the `create-band-store-app` CLI tool, this command provides more flexibility for experienced Band Store developers in creating and configuring their project. It creates a monorepo structure with your Band Store backend in the `apps/backend` directory.

```bash
bandStore new [<dir_name>]
```

## Example

```bash
bandStore new my-band-store-store
```

After running the command, navigate to your project directory and start the development server:

```bash npm2yarn
cd my-band-store-store
npm run dev
```
