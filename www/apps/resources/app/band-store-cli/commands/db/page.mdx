# {metadata.title}

Commands in the Band Store CLI starting with `db:` perform actions on the database.

## db\:setup

Creates a database for the Band Store application with the specified name, if it doesn't exist. Then, it runs migrations and syncs links.

It also updates your `.env` file with the database name.

```bash npx2yarn
npx bandStore db:setup --db <name>
```

<Note title="Tip">

Use this command if you're setting up a Band Store project or database manually.

</Note>

## db\:migrate\:search

Create, alter, and drop the physical search indexes that match the search index definitions in your application. The `db:migrate` command runs this command for you if your application registers the [Search Module](../../../infrastructure-modules/search/page.mdx), which is the default since Band Store v2.21.1. So, run it on its own to migrate the search indexes without touching the database.

```bash npx2yarn
npx bandStore db:migrate:search
```

<Note>

This command is available since Band Store v2.21.1. Learn more about index migrations in the [Reindexing and Migrations guide](../../../infrastructure-modules/search/reindexing/page.mdx).

</Note>

The command prompts you to select which indexes to drop when no definition declares them any more. Pass one of the options below to skip the prompt, which you must do when you run the command in a CI pipeline or another environment without a terminal. Otherwise, the command leaves those indexes in place.

## Reset the Database

The Band Store CLI does not provide a dedicated command to drop or reset the database. To reset your database, drop it manually using PostgreSQL tools, then run `db:setup` to recreate and reinitialize it.

<Note title="Warning" type="warning">

Dropping the database permanently deletes all data. Make sure to back up any data you want to keep before running these commands.

</Note>

For example, using the `psql` command:

```bash
psql -c "DROP DATABASE <db_name>;"
```

Then, run `db:setup` to create the database and run all migrations:

```bash npx2yarn
npx bandStore db:setup --db <db_name>
```
