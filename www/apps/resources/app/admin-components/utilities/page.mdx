# {metadata.title}

<Note>

These utilities are available since Band Store v2.21.0.

</Note>

The `@band-store/dashboard/lib` subpath exports the utilities that the Band Store Admin uses to format data, validate forms, and register custom table and search behavior. Use them in your [admin extensions](!docs!/learn/fundamentals/admin) to handle values the same way the Band Store Admin does.

```tsx
import { getStylizedAmount } from "@band-store/dashboard/lib"
```
