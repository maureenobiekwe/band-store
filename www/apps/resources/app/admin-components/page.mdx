# {metadata.title}

In this section of the documentation, you'll find the components, hooks, layouts, and utilities that the `@band-store/dashboard` package exports, and how to use them in your [admin extensions](!docs!/learn/fundamentals/admin).

Use these exports to build widgets and UI routes that follow the same design conventions as the Band Store Admin, without re-implementing its components.

<Note>

The `@band-store/dashboard` package exports these components, hooks, and utilities since Band Store v2.21.0. Before that version, you had to build the components yourself, as shown in the [archived guides](./archive/page.mdx).

</Note>

The package has the following subpaths:

- `@band-store/dashboard/components`: React components, such as `ActionMenu` and `DataTable`.
- `@band-store/dashboard/hooks`: React hooks, such as `useProducts` and `useComboboxData`.
- `@band-store/dashboard/lib`: Utilities, such as `getStylizedAmount` and `defineSearchEntity`.

<Note title="Tip">

These exports build on the [Band Store UI package](!ui!). Refer to the [Band Store UI documentation](!ui!) for a full list of the underlying components.

</Note>
