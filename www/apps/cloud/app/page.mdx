# Cloud Documentation

Band Store allows teams to build and deploy reliable commerce applications quickly without worrying about infrastructure.

Cloud is designed to bridge the gap between development and production, offering features like direct deployments from GitHub, instant preview environments, and more.

In this guide, you'll learn about Cloud and its features.

## Sign Up for Cloud

New customers in supported regions can try Cloud with a free trial, without entering payment details during sign-up.

Refer to the [Sign Up for Cloud](./sign-up/page.mdx) guide to create your account and start your free trial.

---

## Cloud Features

- **Zero Configuration**: Get started with Cloud in minutes without worrying about server configurations, resources management, or scaling.
- **Backend, Admin, and Storefront Hosting**: Host your Band Store backend, admin, and [storefront](./storefront/page.mdx) with Cloud with zero configuration and automatic environment setup.
- **Direct deployments from GitHub**: Deploy your Band Store projects directly from your GitHub repository, and trigger deployments automatically on every push to the main branch.
- **Multiple Environments**: Create multiple long-lived environments for your projects, such as production and staging, to test changes before going live.
- **Instant Preview Environments**: Isolated preview environments are created on every pull request in your repository.
- **Managed Resources**: Band Store manages your project's resources, including a Postgres database, a Redis server, and an S3 bucket.
- **Band Store Cache**: Benefit from performance improvements of business-critical APIs by reducing heavy operations to the database. [Band Store Cache](./cache/page.mdx) is available out of the box at no additional cost.
- **Band Store Emails**: Send transactional emails such as order confirmations and password resets using [Band Store Emails](./emails/react-email/page.mdx) with zero configuration. Available for all plans.
- **Band Store Search**: Power your storefront's search with full-text and vector search using [Band Store Search](./search/page.mdx), without managing a search engine yourself. Full-text search is available for all plans, and vector search for the Scale and Enterprise plans.
- **Band Store Security**: Protect your projects from malicious traffic with [Band Store Security](./security/page.mdx), including a band-store-specific ruleset, a web application firewall (WAF), DDoS protection, and bot detection, without configuring them yourself. Available for all plans.
- **Zero Downtime Deployments**: Band Store rolls out changes to production with zero downtime, never interrupting your users.
- **Autoscaling**: Environments scale to meet traffic demands.
- **Logging**: Monitor your project's runtime and build logs, so you can easily debug issues in your project.
- **Docs MCP Server**: Access the [Docs MCP server](!docs!/learn/introduction/build-with-llms-ai/docs-mcp-server) in your IDE or AI tools for efficient development.
- **Dedicated Support**: Receive dedicated support from the Band Store team to help you with any issues you may encounter.
- **Agentic Support with CLI**: Use the [Cloud CLI](./cli/agents/page.mdx) to manage your Cloud resources and debug issues with AI agents like Claude Code.
- **Cloud Assistant**: Ask the [Cloud Assistant](./assistant/page.mdx) about Band Store or your projects from anywhere in the dashboard. It helps you find answers, diagnose issues, and remember important information about your projects to assist you better in the future.
- **Fix with AI**: Troubleshoot and resolve build and deployment issues with the help of the [Cloud Assistant](./deployments/fix-with-ai/page.mdx).

## Why use Cloud?

By deploying on Cloud, you can focus on building your application without worrying about infrastructure management.

Since Cloud is built and maintained by the Band Store team for Band Store projects, you get a head start on optimizations and best practices for running Band Store applications in production.

You don't need to handle the complexities of deployment, scaling, resource management, and server configurations with Cloud. Band Store handles it for you, allowing you to deliver a seamless experience to your users.
