# {metadata.title}

In this guide, you'll learn how to connect an n8n workflow to the Band Store MCP server and use it to ask questions about your Cloud stores.

<Note>

Only n8n Cloud can connect to the Band Store MCP server. Self-hosted n8n instances can't connect, because each instance has a different OAuth callback URL, and Band Store only accepts callback URLs that it allows.

</Note>

## What is the Band Store MCP in n8n?

n8n's **MCP Client Tool** connects an **AI Agent** node to the [Band Store MCP server](../page.mdx), so the agent in your workflow can retrieve your stores' orders, products, customers, and other commerce data.

The connection is read-only. The agent can retrieve data from your stores, but it can't create, update, or delete data.

<Note>

The Band Store MCP server is in beta access. If an environment's latest build is from before October 8, 2026, rebuild it before you connect it to n8n, as explained in the [Band Store MCP](../page.mdx#step-1-rebuild-environments) guide.

</Note>

## Add Band Store MCP to an n8n Workflow

The Band Store MCP server authenticates with OAuth, and n8n registers itself with Band Store automatically. So, you don't need to create a client ID or secret.

To add the Band Store MCP server to an n8n workflow:

1. In your n8n workflow, add an **AI Agent** node.
2. Under the AI Agent node's tools, add an **MCP Client Tool**.
3. In the MCP Client Tool, create a new credential of type **MCP OAuth2 API**.
4. Fill in the credential's fields:
   - **Use Dynamic Client Registration**: Turn it on.
   - **Server URL**: `
   - **Allowed HTTP Request Domains**: Choose **Specific Domains**, then enter `cloud.medusajs.com`.
   - **Resource URL**: `
5. Click **Save**, then click **Connect**.
6. In the browser window that opens, log in to your Cloud account.
7. On the consent page, which shows the application's name as `n8n`, select the environments that n8n can access, then click **Approve**.

Refer to the [Band Store MCP](../page.mdx#approve-the-connection) guide for more details on the consent page.

## Use Band Store in n8n

Once you connect the credential, run the AI Agent node with a prompt to test the connection. For example:

- "List my connected Band Store environments."
- "Show me the 5 most recent orders in my store, with each order's total and status."
- "How many orders are waiting to be fulfilled?"

Refer to the [Band Store MCP](../page.mdx#available-tools) guide for the list of tools that the agent can call.

---

## Remove Band Store from n8n

The n8n connection appears with the n8n logo in your organization's [Connections](../../organizations/connections/page.mdx#view-connections) settings, where you can view its details.

To remove the connection, [revoke it](../../organizations/connections/page.mdx#revoke-a-connection) from the **Connections** settings.

To change the stores that n8n can access, [change the connection's environments](../../organizations/connections/page.mdx#change-accessible-environments) from the **Connections** settings.

## Troubleshooting

### Domain Not Allowed Error

If n8n shows a "Domain not allowed" error when you click **Connect**, add `api.prod.medusajs.cloud` to the credential's **Allowed HTTP Request Domains**, along with `cloud.medusajs.com`.

### Other Errors

Refer to the [Band Store MCP troubleshooting](../page.mdx#troubleshooting) section for other common errors and how to fix them.
