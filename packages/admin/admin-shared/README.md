Shared constants, types, and utilities for Band Store's admin packages, such as the list of widget injection zones (`INJECTION_ZONES`, `InjectionZone`) and custom field, route, and layout extension types. It's internal plumbing used by `@band-store/admin-sdk`, `@band-store/admin-vite-plugin`, `@band-store/admin-bundler`, and `@band-store/dashboard`; you don't need to install or import it directly to build admin extensions.
